# WitnessAI

## Privacy-Preserving AI Digital Witness

WitnessAI is an AI-assisted incident documentation system designed to help users capture, organize, and preserve factual information about incidents.

The system is designed to process sensitive information locally where possible, reducing unnecessary dependence on cloud-based AI services.

## Problem

During accidents, safety incidents, disputes, or other unexpected events, people may struggle to accurately remember and organize important details.

WitnessAI helps transform a user's description into a structured incident record containing:

- Extracted facts
- Event timeline
- Missing information
- Uncertain details
- User-verified incident report

## Key Principle

WitnessAI does not invent information. It separates provided facts from missing or uncertain information and allows the user to verify the generated record.
